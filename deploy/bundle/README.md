# sms-gw join bundle

Generated by the gateway (Gateway operations › Modules › sms-gw › Add).

    docker compose run --rm --no-deps sms-gw preflight -config /app/config.yaml -offline
    docker compose up -d

`private/` holds credentials (the single-use enrolment token, the bundle's
TLS keys); `.env` holds generated passwords. Keep both on this host only.
The enrolment token is valid for the lifetime chosen in the wizard; after
the first start the module renews its identity itself.
